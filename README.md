# Retro Games

A collection of retro-styled browser games — no installs, no build step, just open and play. Each game is a single self-contained HTML file.

## Numbers Station

A shortwave-radio memory game. Listen to a broadcast of digits, letters, or both, then key it back before the signal is lost.

- Three channels: Numeric (digits), Alpha (letters), Mixed (letter+digit pairs)
- Every round replays the full sequence so far and adds one more unit
- Three garbled retries per round before the run ends
- End the transmission any time — the results screen shows exactly what you remembered and where it broke
- Pure HTML/CSS/JS, single file, no dependencies

Play it live: https://mahmud-ny.github.io/retro-games/

### Running locally

Just open `index.html` in any browser. No server or build step needed.
